dizzyos

A little LED matrix that hangs above the espresso machine. Every few minutes it fetches izzys-cafe.json from this site and scrolls whatever the cafe is serving that day. That way the menu on the wall and the menu online never disagree.

dizzyos.exe · live

The sign in timetable mode: the next trains at the stop down the block.

How it works

The site publishes the cafe menu as a small JSON feed. A Python script on a Raspberry Pi polls it, diffs it against the last copy, and pushes any change to the 64×32 panel. If the site is unreachable it keeps showing the last menu it saw, with a small ✕ in the corner so I know.
